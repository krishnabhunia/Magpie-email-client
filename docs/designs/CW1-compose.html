E1Find & replace

Ctrl+F opens the bar with Find only; Ctrl+H with Replace. Matches are highlighted in the editor; Enter = next, Shift+Enter = previous; Esc closes. Searches your new text, the quote and the signature.

E2Collapsible quoted text

In replies the quoted message folds to one pill with the sender and date. Click to expand and edit; it folds again only if you fold it. Forwards start expanded. Setting: Settings → General → "Fold quoted text in replies" (on).

E6@mention

Type @ + 2 letters → the same suggestions as the To field. Picking one inserts the name as a link to the address and adds the person to To if not already there (toast "Rahul Sen added to To · Undo").

E3Spelling partly

Right-click a red-underlined word: suggestions · Add to dictionary · Ignore (WebView2's own menu, restyled). Languages = the ones in Windows → Time & language; Settings → General gets "Check spelling" on/off and a link to that Windows page. Not possible: a per-message language picker — WebView2 has no API for it. Say if you want this item dropped.

E4Shortcut sheet

Ctrl+/ or Options → Keyboard shortcuts opens a two-column sheet over the window (full list on the right). Esc closes.

E5Remembered window

Size, position and whether the AI panel was open are saved on close (WindowPlacement.Compose); a window that would open off-screen is pulled back.
